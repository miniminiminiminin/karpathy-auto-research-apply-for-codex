# Positioning And Message Architecture

Message strategy should reduce interpretation work for the user.

```text
MESSAGE_HOUSE := {
  audience := who_must_recognize_themselves,
  problem := pain_or_aspiration_that_matters_now,
  promise := reliable_value_the_product_offers,
  reasons_to_believe := proof_or_mechanism,
  anti_message := what_should_not_be_implied
}

GUARDRAILS := PASS IF
  messaging_leads_with_user_problem_not_internal_feature_language
  AND each_artifact_keeps_one_primary_promise
  AND channel_adaptation_preserves_the_core_promise
  AND support_and_launch_copy_stay_consistent_with_product_reality
  AND voice_and_tone_improve_comprehension_instead_of_decorating_it
  AND accessibility_text_preserves_the_same_promise_and_action_cues
  AND translation_readiness_is_checked_when_message_structure_will_be_reused
```
