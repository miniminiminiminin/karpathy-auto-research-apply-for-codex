# Skill Pattern Checklist

- skill owns one broad operating concern
- trigger is sharp and frontmatter describes when to use it
- output contract is explicit
- `<HARD-GATE>` or equivalent exists when misuse risk is high
- `dot` flow exists when sequence matters
- local `agents/`, `references/`, and `assets/` are justified
- no root-level prompt or template dependency remains
- external material was distilled, not copied verbatim
- any example or best-code snippet has a clear reason and correct placement
