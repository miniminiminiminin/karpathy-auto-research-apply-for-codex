# Design System Master

- Status: optional
- Purpose: record persistent global UI guidance for downstream projects that need stable design rules across iterations
- Scope: global rules only
- Source of truth: page override files may narrow or override these rules for one page, but they should not restate unchanged defaults or become a second master
- Canon boundary: this file supports planning and execution; it does not outrank `purpose.txt`, `rubric.txt`, or the local `CANON/` tree
- Override rule: page files should record only page-specific deviations, the evidence that justified them, and any fallback when the evidence is weak or partial

Fill this file only when a UI-facing project benefits from durable cross-page design guidance.
