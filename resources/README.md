# Resources Guide

This directory keeps source material used during CANON compilation work.

## Structure

- `principles.adactio.com/`
  - canonical capture workspace for the `principles.adactio.com` source
  - contains crawl metadata, raw files, parsed artifacts, logs, and storage notes
- `principles.adactio.com-markdown/`
  - normalized markdown corpus used for owner-batch absorption into `CANON/**`
- loose text notes in the root:
  - `design principles guide.txt`
  - `design principles.txt`
  - `what is design principles.txt`
  - treat these as auxiliary reference notes, not as canonical inventory or completion proof

## Use Rules

- prefer `principles.adactio.com-markdown/**` when compiling durable rules into CANON owners
- use `principles.adactio.com/**` when provenance, crawl coverage, or raw-source inspection is needed
- do not treat loose root notes as authoritative over the captured source trees
- do not delete source material during cleanup unless a narrower owner explicitly requests archival or removal

## Current Status

- `principles.adactio.com` absorption program is coverage-complete at the owner-batch level
- remaining work is hardening deferred rules in `CANON/**`, not re-curating this source tree
