# Sample Usage

Use these prompts when invoking the skill.

## Book Pipeline

```text
Use batch-production to initialize an external workspace for a book chapter pipeline, keep prompt stages as editable files, and run the manifest through the vendored SDK.
```

## Blog Pipeline

```text
Use batch-production to create a workspace for repeated blog generation. I want prompt files, a pipeline JSON, a topics manifest, and batch execution with retries.
```

## Rewrite Batch

```text
Use batch-production to create a workspace outside `.codex`, place rewrite prompts and shared style files there, and run the manifest in bulk.
```
