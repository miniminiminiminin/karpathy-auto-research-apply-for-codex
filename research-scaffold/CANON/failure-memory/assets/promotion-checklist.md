# Promotion Checklist

- is the lesson likely to matter again?
- does it change routing, procedure, or a hard gate?
- if yes, should it move into `SKILL.md`, `assets/`, `references/`, `.codex/AGENTS.md`, or `.codex/README.md`?
- did the lesson change a reusable command path or script contract?
- has the lesson record been updated with promotion status and target path?
