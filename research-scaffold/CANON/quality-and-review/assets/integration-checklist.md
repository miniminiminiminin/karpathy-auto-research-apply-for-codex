# Integration Checklist

## Seam

- seam summary:
- receiver:
- ownership explicit:
- impact scope matches diff:
- upstream dependencies satisfied:
- upstream assumptions checked:
- downstream consumers identified:
- downstream blast radius checked:
- public entrypoints only:
- slice verification passed:
- smallest high-value verification chosen:
- approvals recorded:
- security/privacy review complete:
- rollback owner named:
- release escalation path known:

## Merge

- lowest-level seam first:
- cross-slice verification run:
- adjacent modules untouched:
- async or failure-state coverage checked:
- contract or integration boundary verified:
- proof freshness or evidence gaps recorded:
- actual behavior checked is named:
- remaining uncertainty is explicit:

## Close

- spec review complete:
- code review complete:
- final verification complete:
- before-and-after measurement captured or not needed:
- docs or examples checked when relevant:
- examples exercised or only inspected:
- release approval recorded:
- remaining risks:
- next follow-up:
